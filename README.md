# 🚗 Online Vehicle Rental System

A lightweight, minimal, and fully functional **Vehicle Rental Web Application** built using pure **HTML5, CSS3, and JavaScript**.

Designed as a clean, beginner-friendly academic class project with zero dependencies.

---

## 🌟 Key Features

- **🚗 Vehicle Catalog:** Browse popular cars, SUVs, motorcycles, and scooters (Swift, Creta, Thar 4x4, Bullet 350, Duke 390, Activa 6G).
- **🔍 Category Filters:** Instantly filter vehicles by category (*All, Cars, SUVs, Bikes, Scooters*).
- **⚡ Live Price Calculator:** Select dates and toggle optional add-ons (*Driver +₹1,000/day*) with dynamic price calculation:
  $$\text{Total} = (\text{Daily Rate} \times \text{Days}) + \text{Driver Fee} + 18\% \text{ GST}$$
- **🧾 Printable Confirmation Receipt:** Generates an on-screen booking receipt with a working `Print Receipt` (`window.print()`) button.
- **🛡️ Admin & Host Management:** Add new vehicles to the fleet table dynamically and delete existing listings.
- **📱 Responsive Design:** Clean mobile-friendly layout for both phones and desktops.
- **📁 Single-File Architecture:** All HTML structure, CSS styling, and JavaScript logic are self-contained in `index.html` (Under 20 KB total size).

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup (`<nav>`, `<section>`, `<article>`, `<table>`, `<form>`)
- **CSS3:** Flexbox, CSS Grid, custom buttons, responsive layout
- **JavaScript (Vanilla ES6):** Real-time DOM manipulation and dynamic fare calculation

1. Clone or download this repository:
   ```bash

   ```
2. Navigate to the folder:
   ```bash
   cd vehicle
   ```
3. Open `index.html` in your browser:
   - On Windows: Double-click `index.html` or run:
     ```bash

     ```

## 🌐 Deploy to GitHub Pages (Free Live Website)

Since this project is pure static HTML/CSS/JS, you can host it live on GitHub Pages for free:
1. Go to your GitHub repository **Settings**.
2. Click on **Pages** in the left sidebar.
3. Under **Branch**, select `main` and root `/`, then click **Save**.
4. Within 1 minute, your site will be live at: `https://<your-username>.github.io/<repo-name>/`!
